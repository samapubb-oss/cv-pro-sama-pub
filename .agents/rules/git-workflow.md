# Protocole Git & Sécurité des Déploiements

## Règle Obligatoire : Contrôle Local Avant Publication

- **Étape 1 :** Tout changement demandé par l'utilisateur doit être réalisé et testé **exclusivement en local**.
- **Étape 2 :** Présenter le résultat à l'utilisateur pour qu'il puisse vérifier et valider l'affichage sur son navigateur local.
- **Étape 3 :** **Interdiction formelle de pousser sur GitHub (`git push`) sans la validation et l'autorisation explicite de l'utilisateur.**
