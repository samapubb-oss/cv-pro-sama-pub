# Règles du Projet — Sama Pub (Abdou Lahat Diop)

## 🔒 Règle Absolue : Validation Locale Avant Tout Déploiement GitHub

1. **Modifications locales d'abord :**
   - À chaque demande de changement ou d'évolution formulée par l'utilisateur (design, contenu, responsive, code, assets), applique et teste d'abord les modifications en environnement **local**.
   - Présente le résultat à l'utilisateur pour inspection sur le serveur local (`http://localhost:5173/` ou réseau local).

2. **Validation explicite avant push GitHub :**
   - **Ne JAMAIS pousser (`git push`) sur GitHub de manière autonome.**
   - Pour des raisons de sécurité et de contrôle qualité, montre d'abord le travail accompli et attends l'accord ou la demande expresse de l'utilisateur avant d'envoyer le code sur le dépôt distant (`samapubb-oss/cv-pro-sama-pub`).
